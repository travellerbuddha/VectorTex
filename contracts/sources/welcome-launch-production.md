# Launch (from staging to production)

* Once you finish your implementation with your Test API Key, please submit the [**audit form**](https://docs.google.com/forms/d/e/1FAIpQLSc929M3NHSfPOHyKC9Z-jCT8QlNpVNg1rTvUn_2toRPD2m9sg/viewform). You will then receive instructions about the audit process within a few business days to get approval for production release.
* If everything works well during the audit, you will receive your production API Key.
